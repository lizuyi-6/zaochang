# 见界 · LATTICE

## 品牌方向

**看见知识之间的联系。**

中文名称统一为「见界」，英文为「Lattice」。保留 `/lattice/` 产品入口，以打开的书页与交汇节点表达阅读、理解和知识连接。视觉从通用科技产品转向有编辑感的知识图谱与学习书房。

## 视觉语言

- **松绿 `#164E46`**：品牌标志、关键操作和插画主线。
- **暖纸白 `#F7F4EC`**：阅读背景与插画纸面。
- **琥珀 `#D9A441`**：知识节点和小面积强调，不作为白色小字的背景。
- **鼠尾草绿**：辅助层次、书页、植物与图谱背景。
- 主标题采用编辑式衬线字体；表单、导航和正文保留易读的无衬线字体。
- 插画使用清晰的几何轮廓、印刷式色块和细线，避免依赖微小细节表达封面主题。

## 图形系统

品牌标志为打开的书与上方节点。侧栏、课程提供方、引导页与静态图标使用相同构图。课程封面保留原有十个分类标识，各自以社会联系、生命结构、机器学习、人工智能、历史、提示词、心理、考试、哲学和统计为视觉主题；公开演讲封面另以声波与讲台表达。

共享插画入口：`src/replica/illustrations.tsx`。
静态 SVG：`public/`。
视觉变量：`src/styles/variables.css`。

## 不变的边界

此次品牌更新不改变路由、登录门禁、数据结构、课程选择、生成请求、分享行为或白板教学渲染逻辑。保留已有组件导出、props、封面分类键、翻译键及插值参数。历史会话内容、技术命名与第三方品牌标识不因视觉更新而改写。

## 本地验证

```sh
npm --prefix hyperknow-spa run build
npm --prefix hyperknow-spa run lint
npm run test:lattice
node --test tests/lattice-brand.test.mjs
```

SPA 的正式构建会更新 `public/lattice/`，与主站构建分开。仅验证且不覆盖正式静态产物时，可给 Vite 指定独立输出目录。
