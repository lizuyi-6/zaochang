# 回归复查走查 — 见界白板 · 2026-10-03

> 完整报告见同目录 `REGRESSION.md`。本文件是 skill 要求的走查叙事。

## scope
2026-10-02 审查报出 11 条问题、gate `not_ready`。此后生产推进 7 个 commit(`9a59f77` → `34c8bf9`),其中 `b5d5bd9` 修复 8 条、新增「自由讲座」功能与 5 个白板观感 commit。本轮目标:**验证修复是否真的生效 + 审查新功能**。

## user goal
用户指令:「重新录制,我们上线了一堆更新」。真实诉求不是重新普查,而是**确认上线的这批改动是否值得信任**。

## cue → hypothesis
最强的一条 cue 来自上一轮报告本身:P-001 记录「客户端 65s < 服务端 130s」,而团队昨晚把服务端提到 130s 却没动客户端。若同类失配再次发生,昨晚的修复在冷实例上会整体失效。

## experiment
1. **源码层**:逐条读 8 项修复的落点,确认不是只改声明未改调用点
2. **运行时**:线上直连 + 浏览器实测(401/404 状态码、DOM 属性、命中框几何)
3. **变异层**:反向改坏新契约测试的关键输入,验证守卫会变红
4. **新功能**:`#/whiteboard?topic=<主题>` 两段式端到端

## observed defect(本轮新发现)

### R-001【中】旧产品名 Hyperknow 残留 8 处用户可见文案
`grep -rn Hyperknow hyperknow-spa/src` 命中 8 处硬编码 `L()` 字面量。9 月 `fe6e5f6` 更名时**只改了 i18n 字典的值**,漏掉字面量。其中 `SettingsModal.tsx:242-243` 是**账户删除申请邮件正文**、`boardExport.ts:395` 是**导出板书标题**——都会以旧代号出现在用户面前。运行时已在讲座简介正文实证。

### R-002【低-中】自由讲座英文简介拼接崩
`WhiteboardPage.tsx:280` 把中文主题无引号嵌入英文句,线上渲染为 `This session opens 为什么说…而不是加锁 the way every Hyperknow lesson does:`。同一模板的中文变体处理正确,英文变体未跟进。该句同时是旁白/字幕文案,会被 TTS 念出。

### R-003【低】旁白标点/错字(模型输出)
两次旁白出现孤立「未闭合,及「传导辑径」应为「路径」。

### R-005【低】4 项修复无守卫测试
P-002(55s<60s)与 P-001 同族却无契约测试;P-003/P-006/P-011 同样无覆盖。

## root cause
R-001 的根因是**更名的执行方式**:改了 i18n 字典的值,没做仓库级字面量清扫。R-002 的根因是**双语模板只做了一侧**:中文变体的语法适配没有镜像到英文变体。

## change
**本轮未做任何源码修改**(audit 模式)。唯一的临时改动是变异测试的输入,每次当场确认写入并立即还原,还原后已复跑确认守卫恢复绿色。
